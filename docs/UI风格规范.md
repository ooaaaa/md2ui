# md2ui UI 风格规范

供其他 AI 或开发者参考，生成风格一致的前端界面。

## 整体风格

- 清爽、克制、留白充足，类似 GitHub 文档 + Vue 官网的混合气质
- 亮色为主，绿色主色调，无暗色模式
- 圆角柔和（6-8px），阴影极轻，边框用半透明主色
- 字体使用系统原生字体栈，代码用等宽字体
- 交互反馈轻量：hover 变色/变背景，transition 0.15s，无夸张动画

## 布局特征

- 三栏布局：左侧导航树 + 中间内容区 + 右侧文档大纲
- 内容区最大宽度 960px，水平居中
- 侧边栏宽度 200-400px，可拖拽调整
- 面板之间用 1px 边框分隔，不用阴影
- 移动端自动切换为抽屉式导航

## 组件风格

### 按钮

- 主按钮：绿色背景 + 白色文字，圆角 4-6px
- 次要按钮：透明背景 + 边框，hover 时边框变绿
- 图标按钮：22-32px 正方形，无边框，hover 加浅灰背景
- 禁用态：opacity 0.3-0.5

### 输入框

- 1px 边框，圆角 6px
- focus 时边框变绿 + 外发光 `box-shadow: 0 0 0 3px rgba(66,184,131,0.1)`
- placeholder 用辅助色

### 代码块

- 白色背景，绿色半透明边框
- 顶部 header 栏显示语言标签 + 操作按钮（复制、换行切换）
- header 背景 #f7f9f8，字号 11-12px
- 代码区带行号，行号列右侧有 1px 分隔线
- 高亮主题：GitHub Light 风格

### 表格

- 1px 边框，表头背景 #f2f5f3，加粗
- 偶数行无背景色，hover 行加浅色 #f7f9f8
- 支持全屏查看弹窗

### 引用块

- 左侧 3px 绿色竖线
- 浅绿背景 rgba(66,184,131,0.03)
- 右侧圆角 6px

### 导航项

- 左侧树形结构，缩进层级
- 选中态：浅绿背景 + 左侧 3px 绿色边框 + 绿色文字
- hover：浅灰背景
- 文件夹可折叠，带 chevron 图标

### 弹窗/浮层

- 白色背景，1px 边框，圆角 8-12px
- 阴影 `0 4px 16px rgba(0,0,0,0.1)`
- 遮罩 rgba(0,0,0,0.4)

## 间距规律

- 组件内部 padding：8-16px
- 元素间距：4-12px
- 段落间距：12px
- 标题上方间距：16-24px
- 页面边距：20-32px

## 交互细节

- 所有 hover/focus 过渡：transition 0.1-0.15s
- 按钮点击无 scale 变化，仅颜色变化
- 滚动条：6px 宽，圆角，浅灰色，hover 加深
- 工具提示（tooltip）：深色背景 #1f2328，白色文字，11px，圆角 4px
- 复制成功反馈：绿色文字 + 浅绿背景，1.5s 后消失

## 图标

- 使用 Lucide 图标库
- 图标尺寸：14-20px，与文字对齐
- 颜色跟随文字层级（主色/次要/辅助）

## 响应式断点

```
桌面端：> 1200px（三栏完整显示）
平板端：768-1200px（隐藏右侧大纲）
移动端：< 768px（抽屉导航 + 浮动按钮）
```
